النسخ الاحتياطي على Google Drive
نسخ احتياطي تلقائي يومي — يُحفظ في مجلد MedLab Pro بحسابك
⚪ غير مرتبط — اضغط "ربط الحساب" للبدء
نسخ تلقائي يومي:
1
إنشاء مشروع Google Cloud
• افتح console.cloud.google.com
• اضغط New Project → أعطه اسم مثل MedLab Pro → اضغط Create
• من القائمة الجانبية اختر APIs & Services → Library
• ابحث عن Google Drive API واضغط عليه → اضغط Enable
2
إنشاء OAuth Client ID
• اذهب إلى APIs & Services → Credentials
• اضغط Create Credentials → OAuth 2.0 Client ID
• إذا طُلب منك إعداد OAuth consent screen:
  — اختر External → أدخل اسم التطبيق → اضغط Save
• نوع التطبيق: اختر Web application
• في Authorized JavaScript origins أضف عنوان برنامجك:
  http://localhost:5500
• اضغط Create — ستظهر نافذة فيها Client ID، انسخه
3
ربط البرنامج بـ Google Drive
• اضغط زر 🔗 ربط حساب Google أعلاه
• ستظهر نافذة تطلب منك إدخال Client ID — الصق ما نسخته
• ستفتح نافذة Google لتسجيل الدخول → وافق على الصلاحيات
• ✅ بعد الموافقة سيظهر 🟢 مرتبط ويمكنك تفعيل النسخ التلقائي
4
تفعيل النسخ التلقائي
• بعد الربط فعّل مفتاح نسخ تلقائي يومي
• النسخ تُحفظ في مجلد MedLab Pro داخل Google Drive الخاص بك
• يمكنك الضغط على ☁️ نسخ احتياطي الآن للنسخ الفوري
⚠️ ملاحظة: الـ Client ID مرتبط بعنوان البرنامج — إذا غيّرت العنوان يجب تحديث Authorized JavaScript origins في Google Cloud Console وإعادة الربط.
